# VerNel — quickshell vertical panel

A custom [quickshell](https://quickshell.outfoxxed.de/) desktop shell for
[Hyprland](https://hyprland.org/), replacing waybar + swaync with a vertical
bar on the right edge and native, macOS-style popups for notifications, quick
settings, audio and MPRIS.

> **⚠️ Disclaimer: this is a hobby project.** It is "vibecoded" — written
> (with a lot of AI assistance) to move fast, iterate on features, and look
> nice on the author's own machine. It is not engineered for other people's
> setups, is heavily personalized, and code quality/robustness was consciously
> traded for speed of development. Fork it for ideas, not as a drop-in shell.

## Features

- Vertical right-edge bar with a morphing hover highlight
  - Notifications, clock (with calendar popup), volume/audio, MPRIS player,
    system tray, screen brightness, battery, temperature, workspaces
- **Native notification daemon** (replaces swaync)
  - Toast notifications with action buttons (e.g. bluetooth pairing)
  - One-click copy for 6-digit pairing codes (KDE Connect)
  - Auto-hide countdown that **freezes while you hover**; toasts become more
    opaque on hover; ✕ close button
  - Notification center with history + clear
  - Do-not-disturb toggle
- **Quick settings** panel
  - Wi-Fi (list + connect), bluetooth, ethernet, night light, idle inhibitor
  - Power / lock shortcuts
  - **Mirror-to-HDMI** button: duplicate eDP-1 onto HDMI-A-1 (or stop it)
- **OSD overlay** for caps/num lock, touchpad, volume and brightness
- MPRIS detail popup with progress bar + transport controls
- App tray with native context menus (themed via kvantum/matugen)
- Colors generated by [matugen](https://github.com/InioX/matugen) and hot-reloaded on change

## Dependencies

- [quickshell](https://quickshell.org/) (0.3.x)
- [Hyprland](https://hyprland.org/) (0.56+ — uses the Lua `hyprctl eval` API)
- [JetBrainsMono Nerd Font](https://www.nerdfonts.com/font-downloads)
- Optional but used: matugen, hyprlock, wlogout, nm-connection-editor,
  blueman-manager, hyprsunset, [awww](https://codeberg.org/LGFae/awww)

## Usage

1. Clone this repo
2. Copy this repo or make a symbolic link to `~/.config/quickshell/`
3. Run from terminal using `quickshell -c VerNel` or `qs -c VerNel`

you can also add hyprland auto startup. this is an example:

```lua
hl.on("hyprland.start", function()
    hl.exec_cmd("qs -c VerNel")
end)
```

### Keybinds (via Hyprland IPC)

```sh
# toggle notification center
quickshell ipc -c VerNel call VerNel toggleNotifications

# toggle quick settings
quickshell ipc -c VerNel call VerNel toggleQuickSettings

# toggle volume panel
quickshell ipc -c VerNel call VerNel toggleAudioControls

# toggle mpris widget
quickshell ipc -c VerNel call VerNel toggleMprisDetail

# toggle calendar widget
quickshell ipc -c VerNel call VerNel toggleCalendar

# toggle wallpaper selector
quickshell ipc -c VerNel call VerNel toggleWallpaperSelector

# hot-reload after theming
quickshell ipc -c VerNel call VerNel reload
```

## Customization

- All geometry, colors and animation durations live in `widgets/Config.qml`.
- Colors come from `matugen-colors.qml` (generated by matugen, gitignored).
  Point matugen's quickshell template at `matugen-colors.qml` and add
  `post_hook = 'quickshell ipc -c ricegueh call ricegueh reload'` to your
  `matugen/config.toml`.
- For wallpaper selector, place your wallpaper in `~/Pictures/wallpapers/`

### Matugen config example.

```toml
[templates.quickshell]
input_path = '~/.config/matugen/templates/quickshell-colors.qml'
output_path = '~/.config/quickshell/ricegueh/matugen-colors.qml'
post_hook = 'quickshell ipc -c ricegueh call ricegueh reload'
```
